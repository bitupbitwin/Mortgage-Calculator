# 应用图标

把图标文件放在这个目录,然后运行图标生成命令。

## 需要准备的文件

| 文件名 | 尺寸 | 说明 |
|--------|------|------|
| `app_icon.png` | 1024×1024 | 主图标,不透明背景,四角填满 |
| `app_icon_foreground.png` | 1024×1024 | 自适应图标前景,**透明背景**,内容居中占约 66%(四周留安全边距) |

## 生成命令

```bash
flutter pub get
flutter pub run flutter_launcher_icons
```

执行后会自动生成 `android/app/src/main/res/mipmap-*` 下各分辨率图标。

## 图标设计建议(房贷计算器)

- 主色:深绿 `#0C2B24`(与 App 主题一致)
- 元素:房子 🏠 + 计算器/百分号,简洁醒目
- 避免使用真实银行 logo、人民币符号过度突出(部分商店金融类审核敏感)
- 不要带文字(小尺寸看不清)

可以用 Figma / Canva / 即时设计 制作,或找设计外包。导出 1024×1024 PNG 即可。
