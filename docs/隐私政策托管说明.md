# 如何把隐私政策发布成公开网址

国内商店提交时需要一个**公开可访问的隐私政策网址**。这里用 GitHub Pages 免费托管 `docs/privacy-policy.html`。

## 启用 GitHub Pages(3 步)

1. 打开仓库 → **Settings** → 左侧 **Pages**
2. **Source** 选 `Deploy from a branch`;**Branch** 选 `main`,目录选 `/docs`,点 **Save**
3. 等 1~2 分钟,页面顶部会显示你的网址,格式为:
   ```
   https://bitupbitwin.github.io/Mortgage-Calculator/privacy-policy.html
   ```

把这个网址填到各商店的"隐私政策链接"字段即可。

## 备选方案(国内访问更稳)

GitHub Pages 国内访问偶尔不稳。若担心商店审核访问慢,可改用:
- **Gitee Pages**:把仓库镜像到码云,同样方式开启 Pages
- **腾讯文档 / 语雀**:把 `PRIVACY_POLICY.md` 内容贴上去,设为公开,用分享链接

## 验证

发布后用手机流量(非 WiFi)打开网址,确认能正常显示,再提交商店。
