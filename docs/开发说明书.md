## 一、项目概述

### 1.1 产品定位
"房贷计算器"是一款面向购房人群的**纯本地、无广告**的贷款测算工具。区别于市面常见计算器，它支持**公积金+商业贷组合贷款**、**多节点分项提前还款**、**月冲 vs 年冲对比**等进阶场景，帮助用户在购房决策前算清"全程总支出"这笔大账。

### 1.2 目标用户
- 准备买房、需要测算月供与利息的购房者
- 已有房贷、考虑提前还款的还贷人群
- 对比公积金不同使用方式（月冲/年冲）的公积金贷款用户

### 1.3 核心价值
| 痛点 | 本应用解法 |
|------|-----------|
| 组合贷算不清 | 公积金 + 商业贷分别配置利率期限，自动推算 |
| 真实购房成本被低估 | 中介费、契税并入首付，展示"购房全程总支出" |
| 提前还款省多少不知道 | 多节点模拟，缩短期限 vs 减少月供对比 |
| 公积金怎么用最划算 | 月冲 vs 年冲省息量化对比 |
| 隐私顾虑 | 纯本地运算，不联网、不收集信息 |

### 2.2 关键业务规则

**贷款金额计算**
```
贷款总额   = 房价 − 首付            （税费不计入贷款）
实际首付   = 首付 + 中介费 + 契税    （税费购房初期一次性缴纳）
公积金贷款 = min(用户输入额度, 贷款总额)
商业贷款   = 贷款总额 − 公积金贷款   （自动推算）
```

**购房全程总支出**
```
总支出 = 房价 + 中介费 + 契税 + 贷款总利息
       = 实际首付 + 还款总额          （等价写法）
```

**提前还款规则**
- 同一时间节点可同时对公积金、商贷提前还款，也可只填其一
- 提前还款金额先抵扣本期月供后的剩余本金，多余部分自动 clamp 不产生负余额

│  house / flush / schedule / about    │

## 四、核心算法

### 4.1 等额本息
每月还款额固定：
```
M = P × r × (1+r)ⁿ / [(1+r)ⁿ − 1]
P=本金  r=月利率(年利率/12)  n=剩余期数
```
每月利息 = 当前余额 × r，本金 = M − 利息。

### 4.2 等额本金
每月本金固定，利息递减：
```
每月本金 = 余额 / 剩余期数   （减少月供模式）
         或 = 初始本金 / 总期数   （缩短期限模式）
每月还款 = 本金 + 余额 × r
```

### 4.3 提前还款两种模式
| 模式 | 月供 | 期限 | 省息 |
|------|------|------|------|
| 缩短期限 shortenTerm | 不变(固定初始值) | 缩短 | 更多 |
| 减少月供 reducePayment | 逐月重算降低 | 不变 | 较少 |

### 4.4 月冲 vs 年冲
- **月冲**：公积金每月抵扣月供，按正常摊销，作为基准
- **年冲**：每年末用 12 个月公积金一次性提前还款（缩短期限），更快减少本金 → 省息更多

### 4.5 计算正确性
全部 14 项核心逻辑已通过 Python 逐步推导验证，关键值：
- 200万/30年/3.05% 等额本息首月月供 = 8486.11 元 ✓
- 等额本金首月月供 = 10638.89 元 ✓
- 等额本息总利息 = 105.50万 ✓

## 六、开发与构建

### 6.1 环境要求
- Flutter SDK 3.x（含 Dart 3.x）
- Android SDK，JDK 17
- 真机或模拟器 Android 7.0+

### 6.2 常用命令
```bash
flutter pub get                  # 安装依赖
flutter run                      # 真机调试(热重载)
flutter test                     # 跑单元测试
flutter build apk --debug        # 测试包(免签名)
flutter build apk --release      # 正式包(需签名)
```

> ⚠️ **不要**用 Android Studio 菜单 `Build → APK`，必须用 `flutter build`，否则生成的包缺 Flutter Engine 会闪退。
