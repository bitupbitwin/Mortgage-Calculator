## 二、软件开发的目的与背景

购房是大多数家庭重要的经济决策,而房贷涉及公积金贷款、商业贷款、组合贷款等多种形式,以及等额本息、等额本金等还款方式,普通购房者难以准确估算月供、总利息及购房全程支出。市面工具多存在广告多、需联网、不支持组合贷与提前还款模拟等问题。

本软件旨在提供一款**纯本地运行、无广告、计算专业**的购房贷款计算工具,帮助购房者在购房前清晰掌握各项成本,做出理性决策。

## 三、软件的主要功能

### 3.1 购房综合计算
用户输入房屋总价、首付金额、中介费率、契税率,软件自动计算:
- 中介费、契税金额
- 实际首付(首付 + 税费)
- 贷款总额(房价 − 首付)

### 3.2 组合贷款计算
支持公积金贷款与商业贷款分别配置贷款金额、年利率、贷款期限。公积金贷款额度优先,商业贷款金额自动推算(贷款总额 − 公积金贷款)。

### 3.3 还款方式
支持两种主流还款方式:
- **等额本息**:每月还款额固定
- **等额本金**:每月偿还本金固定,利息递减

### 3.4 提前还款模拟
- 支持设置多个提前还款节点(按年月)
- 每个节点可分别针对公积金贷款、商业贷款提前还款
- 支持新增、编辑、删除节点
- 两种提前还款模式:
  - **缩短期限**:月供不变,提前还清,节省利息更多
  - **减少月供**:期限不变,降低每月还款额

### 3.5 月冲 vs 年冲对比
对比公积金"按月冲还月供"与"按年一次性提前还款"两种使用方式的省息差异,帮助用户决策公积金的最佳使用方式。

### 3.6 计算结果展示
- 购房全程总支出(房价 + 税费 + 总利息)
- 购房费用明细
- 首月月供、总利息
- 逐月还款计划明细表(本金、利息、剩余本金)

### 3.7 数据本地持久化
用户输入的参数自动保存在设备本地,下次打开自动回填。

## 四、软件的技术特点

1. **跨平台框架**:基于 Flutter 开发,UI 流畅,性能优异。
2. **响应式状态管理**:采用 Riverpod 实现数据与界面的实时联动,任意参数修改即时反映到计算结果。
3. **纯本地运算**:所有计算在设备端完成,不依赖网络,保护用户隐私。
4. **精确的金融算法**:
   - 等额本息月供公式:M = P×r×(1+r)ⁿ / [(1+r)ⁿ − 1]
   - 等额本金逐月本金摊销
   - 提前还款后剩余本金重新计算还款计划
5. **数据可视化**:采用 fl_chart 图表库展示还款构成。

## 六、软件的安装与使用

1. 从应用商店下载并安装本软件。
2. 打开应用,进入"房贷计算器"主界面。
3. 依次输入房屋信息、首付、组合贷款配置。
4. (可选)添加提前还款节点。
5. 选择还款方式与提前还款模式。
6. 点击"立即计算",查看购房全程总支出与还款明细。
7. 可进入"月冲 vs 年冲"页面对比公积金使用方案。

## 七、软件结构说明

软件采用分层架构,主要模块如下:

```
lib/
├── main.dart                  应用入口与主题配置
├── core/                      核心计算与数据模型
│   ├── calculator.dart        贷款计算引擎(等额本息/本金、提前还款、月冲年冲)
│   ├── models.dart            贷款数据模型
│   ├── house_models.dart      购房组合贷数据模型
│   └── formatters.dart        数值格式化工具
├── providers/                 状态管理
│   ├── calculator_provider.dart
│   └── house_provider.dart
└── features/                  功能界面
    ├── house/                 购房综合计算(主页、结果、提前还款)
    ├── flush/                 月冲 vs 年冲对比
    ├── schedule/              还款计划明细表
    ├── about/                 关于与隐私政策
    └── ...
```

代码总量约 4700 行。
