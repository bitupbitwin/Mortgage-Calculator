## ① 资质准备(最关键,先启动,因为耗时最长)

国内安卓商店审核比 Google Play 严格,个人开发者上架需要以下资质。**软著和 APP 备案是主要瓶颈,务必尽早开始。**

### 1.1 开发者实名认证 ✅ 必需
- 各商店开发者平台注册时用**身份证**完成个人实名认证。
- 准备:身份证正反面照片、本人手持身份证照(部分商店要)、银行卡、手机号。
- 耗时:1~3 个工作日。

### 1.2 软件著作权证书(软著) ⚠️ 多数商店必需
- **华为、小米、OPPO、vivo、应用宝**等主流商店,新应用上架基本都要求提供软著证书,尤其工具/金融类。
- 申请途径:
  - 自己申请:中国版权保护中心官网,**免费但慢(30~40 个工作日)**。
  - 代办加急:淘宝/代理机构,几百元,**3~10 个工作日**出证。
- 申请需要材料:
  - 源代码(前后各 30 页,共 60 页,本项目 `lib/` 下代码足够)
  - 软件说明书(功能文档,可用本仓库 README + 截图整理)
  - 个人身份证
- **建议:现在就去申请,边等证边做后面的步骤。**

### 1.3 移动应用 APP 备案(工信部) ⚠️ 强制
- 自 2023 年起,所有上架 App 必须完成**工信部移动互联网应用程序备案**,否则会被下架。
- 个人开发者无服务器的情况:
  - 多数商店在提交时会引导你通过该商店完成"应用备案"(商店作为分发平台协助)。
  - 或在**工信部 ICP/IP/域名信息备案管理系统**直接备案。
- 需要:应用名称、包名、版本、签名 MD5、公钥、开发者实名信息。
- 备案通过后会得到**备案号**,需在应用内或商店页面展示。

### 1.4 计算机软件相关说明
- 本应用为**纯计算工具,不涉及金融业务、不收款、不放贷**,不需要金融牌照/ICP 经营许可证。
- 但商店分类时**建议选"实用工具",不要选"金融理财"**,可大幅降低审核门槛(金融类需额外资质)。

### 2.2 你需要在本地完成的(需 Flutter 环境)

#### 第一步:生成签名密钥(只做一次,务必备份!)
```bash
# 在项目根目录执行
keytool -genkey -v -keystore android/app/fangdai-release.jks \
  -keyalg RSA -keysize 2048 -validity 10000 -alias fangdai
```
按提示输入密码、姓名等。**生成的 `.jks` 文件和密码必须永久妥善保存**,丢了就无法再更新这个 App(只能换包名重新上架)。

然后复制配置模板并填入密码:
```bash
cp android/key.properties.example android/key.properties
# 编辑 android/key.properties,填入刚才设置的密码
```

#### 第二步:准备并生成图标
1. 设计一张 1024×1024 的 PNG 放到 `assets/icon/app_icon.png`(详见该目录 README)。
2. 运行:
```bash
flutter pub get
flutter pub run flutter_launcher_icons
```

#### 第三步:构建发布包
**⚠️ 国内商店要的是 APK,不是 AAB(AAB 是 Google Play 专用)。**
```bash
flutter clean
flutter build apk --release
```
产物在:`build/app/outputs/flutter-apk/app-release.apk`

如需更小体积,可按 CPU 架构分包:
```bash
flutter build apk --release --split-per-abi
# 一般上传 arm64-v8a 版本即可覆盖绝大多数现代手机
```

#### 第四步:获取签名信息(备案/商店需要)
```bash
keytool -list -v -keystore android/app/fangdai-release.jks -alias fangdai
```
记下 **MD5、SHA-1、SHA-256** 指纹,备案和部分商店登记时要用。

## ③ 商店素材(文案 + 图片)

详见同目录 `商店素材文案.md`,已为你写好可直接用的应用描述、一句话简介、更新日志等。

你还需要准备的**图片素材**:
- **应用图标**:512×512 PNG(商店展示用,和 App 内图标一致)
- **应用截图**:至少 3~5 张,手机实机截图(竖屏)。建议截:
  1. 主页(购房综合计算输入界面)
  2. 提前还款计划列表
  3. 计算结果页(购房全程总支出)
  4. 月供明细 / 还款计划表
  5. 月冲 vs 年冲对比页
- **截图尺寸**:用真机或模拟器截图即可,常见 1080×1920 或更高。
- (可选)**应用宣传图/Banner**:部分商店需要,1024×500 左右。

## ④ 各商店提交流程概览

| 商店 | 开发者平台 | 个人可上架 | 备注 |
|------|-----------|-----------|------|
| 华为应用市场 | developer.huawei.com | ✅ | 用户量大,审核较严,要软著 |
| 小米应用商店 | dev.mi.com | ✅ | 流程清晰 |
| OPPO 软件商店 | open.oppomobile.com | ✅ | 要软著 |
| vivo 开发者平台 | dev.vivo.com.cn | ✅ | 要软著 |
| 应用宝(腾讯) | open.tencent.com | ✅ | 覆盖微信/QQ 生态 |
| 荣耀应用市场 | developer.honor.com | ✅ | 可选 |

**通用提交步骤**:
1. 注册并实名认证开发者账号。
2. 创建应用,填写包名、应用名称、分类(选"实用工具")。
3. 上传 APK、图标、截图。
4. 填写应用描述(用 `商店素材文案.md`)、隐私政策链接。
5. 上传软著证书、完成 APP 备案。
6. 提交审核,1~7 个工作日出结果。

### 隐私政策怎么提供链接?
商店通常要一个**公开可访问的隐私政策网址**。两种方式:
- 把 `PRIVACY_POLICY.md` 发布到 GitHub Pages / Gitee Pages(免费),得到一个网址。
- 或用语雀、腾讯文档等公开文档链接。
